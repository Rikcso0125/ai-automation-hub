# ✍️ Tömeges Termékleírás és SEO Optimalizáló Motor

Nyers beszállítói adatokból percek alatt készít vevőcsalogató, Google-re optimalizált termékleírásokat, meta tag-eket, Schema.org JSON-LD-t és címsorokat több ezer termékre egyszerre.

---

## 🌟 Főbb Képességek

### 1. Szövegstílus és Célközönség (1. Kérdés - C)
* **B2B Szakmai (`b2b_technical`):** Műszaki pontosság, szabványok, strukturált HTML táblázat.
* **B2C Érzelmes (`b2c_emotional`):** Figyelemfelkeltő hook, előnyök, bullet pointok, konverziós CTA.
* **Kettős Hibrid (`hybrid_dual`):** Felül laikus vevőcsalogató előnyök, alul mérnöki B2B adatlap.

### 2. Keresőoptimalizálás és Strukturált Adatok (2. Kérdés)
* **SERP Csomag:** Meta Title (max 60 kar), Meta Description (max 155 kar), H1/H2 címek, tiszta URL slug.
* **Schema.org Rich Snippets:** Product és FAQ JSON-LD struktúra a csillagos értékelésekhez és GYIK kiemelésekhez.
* **Teljes SEO Suite:** A SERP és Schema elemek együttes generálása.

### 3. Webshop Szinkron és Minőségbiztosítás (3. Kérdés)
* **Közvetlen API Szinkron (`direct_api_bulk_sync`):** Shopify, WooCommerce, UNAS, Shoprenter.
* **CSV/Excel Export (`csv_excel_export`):** Importálható táblázat e-commerce vezetőknek.
* **Interaktív Diff Kapu (`diff_review_gate`):** Régi vs új szöveg összehasonlító kapu jóváhagyási gombbal.
