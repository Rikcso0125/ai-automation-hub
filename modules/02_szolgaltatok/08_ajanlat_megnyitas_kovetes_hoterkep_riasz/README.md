# Ajánlat Megnyitás-Követés & Hőtérkép Riasztás

## 📌 Áttekintés
Valós időben érzékeli, amint az érdeklődő ügyfél megnyitja a kiküldött ajánlatot mobilján vagy számítógépén.
1. **Élő Értesítés az Értékesítőnek:** WhatsAppon, Telegramon, Telnyx SMS-ben és Web Dashboard pushban azonnal megérkezik a riasztás.
2. **1-Kattintásos Tárcsázó Link (`tel:...`):** Az értékesítő a telefonján egyetlen koppintással felhívhatja az ügyfelet abban a percben, amikor az ajánlatot nézi.
3. **Viselkedési Hőtérkép & Részletes Időtartam:** Méri az eltöltött másodperceket, a görgetési mélységet és a szekciók (árak, garancia, műszaki tartalom) egyedi figyelmét.
4. **AI Döntési Forróság Index (0-100):** Cold, Warm, Hot, vagy Burning Hot besorolás felkészítő beszélgetésnyitó tippekkel.
5. **Újramegnyitási Sürgősségi Riasztás:** Ha az ügyfél este többször is újranyitja az ajánlatot (pl. családtaggal, döntéshozóval tárgyalja), kiemelt riasztást kap az értékesítő.
