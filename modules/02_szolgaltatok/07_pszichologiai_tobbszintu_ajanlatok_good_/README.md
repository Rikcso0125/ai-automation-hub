# Pszichológiai Többszintű Ajánlatok (Good-Better-Best Csomagok)

## 📌 Áttekintés
Egyetlen merev ár helyett a rendszer automatikusan 3 különböző szintű ajánlati csomagot állít össze:
- **Good (Alap / Racionális):** Belépő szintű minőségi berendezés, törvényi garancia, alap szerelés.
- **Better (Ajánlott Prémium – LEGNÉPSZERŰBB):** Kiemelt megjelenés, magasabb energiahatékonyság, beépített WiFi, +2 év kiterjesztett garancia és ajándék 1. évi karbantartás.
- **Best (VIP All-Inclusive):** Csúcskategóriás dizájn modell, 5 év teljes körű jótállás, 2 év díjmentes karbantartás, 24 órás helyszíni cseregarancia.
