# Kézírásos Munkalapok és Jegyzőkönyvek OCR Digitalizálása

## 📌 Áttekintés
Kézzel kitöltött, tollal aláírt helyszíni papír munkalapok és szerviz jegyzőkönyvek azonnali Vision OCR digitalizálása.
1. **Többcsatornás Beküldés:** WhatsApp / Telegram fotó, Web Dashboard mobilos kamera/fájl feltöltés.
2. **Teljes Adatkinyerés:** Munkalapszám, megrendelői adatok, elvégzett tételek, felhasznált anyagok és munkaórák.
3. **Kézi Aláírás Érzékelése:** Ellenőrzi mind a szakember, mind a megrendelő szignójának meglétét (hiány esetén figyelmeztet).
4. **Digitális A4 PDF Munkalap:** Hivatalos, kristálytiszta digitális PDF generálás (`output/munkalapok/*.pdf`).
5. **Számlázási és Értesítési Szinkron:** Előkészíti a számlatervezetet (Billingo/Számlázz.hu/ERP) és kiküldi a másolatot az ügyfélnek.
6. **Human Review Kapu:** 80% alatti OCR bizonyosság vagy hiányzó aláírás esetén sárga jelzéssel felülvizsgálatra küldi a munkalapot.
